# finance-app

Turborepo monorepo for the finance expenditure tracker.

## What's inside?

### Apps

- `api-backend`: API backend (placeholder)

### Packages

- `@repo/eslint-config`: shared ESLint configs
- `@repo/typescript-config`: shared TypeScript configs

## Develop

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
```
